# CIS261 Course Project – Phase 1

**Author:** Jim Bolding (@freebold1984)  
**Course:** CIS261 – Object Oriented Computer Programming I  
**Assignment:** Create and Call Functions with Parameters

This repository contains the Phase 1 deliverable for the CIS261 Course Project.  
The primary file for grading is `week3_assignment.py`, which automates payroll calculations using modular Python functions.

### ✅ Features
- Input validation for hours, rate, and tax
- Modular functions for data entry, calculation, and display
- Loop terminates on `"End"` input
- Summary totals for all employees
